# v0.1.0: Initial Release

🎉 **First release of Partner!**

## ✨ Features

- **Partner Core**: Task queue, knowledge base, journal system
- **Hermes Agent Integration**: Full support with skill registration
- **CLI Commands**: `partner setup`, `partner status`
- **Basic Research Cycle**: Background task execution
- **Workspace Management**: Automatic workspace creation and configuration

## 🤖 Supported Agents

| Agent | Status |
|-------|--------|
| 🔮 Hermes Agent | ✅ Full support |

## 📦 Installation

```bash
git clone https://github.com/zty522/partner.git
cd partner
pip install -e .
partner setup
```

## 💬 Usage

```bash
# Start talking to Partner
hermes

# Then say:
"Hey Partner, what have you been doing?"
```
