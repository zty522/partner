# v0.1.0: Stable Release

🚀 **First stable release with complete core features!**

## ✨ Features

### Event System (Autonomous Research)
- **Autonomous Research Cycles**: Runs research tasks every 15-30 minutes
- **Event Templates**: 8 predefined research workflows (literature search, project audit, etc.)
- **Knowledge Gap Detection**: Automatically identifies areas needing deeper research
- **Event Statistics**: Tracks completed events, spawned events, phases executed

### Conversation Engine V2
- **Multi-turn Context**: Remembers conversation history and context
- **Response Generator**: Supports "show me the 3rd one", "next page", etc.
- **Proactive Notifications**: Alerts you about important findings
- **User Preference Learning**: Adapts to your research style

### Self-Evolution Engine
- **Strategy Learner**: Learns which task types are most successful
- **Memory Pruner**: Automatically cleans outdated knowledge
- **CPE Guard**: Monitors core capabilities, alerts if degraded

### Strategy Map
- **DAG Structure**: Visual research roadmap
- **Fork Discovery**: Automatically finds new research directions
- **Policy Selection**: 5-factor scoring for next action

### Messaging Integration
- **QQ Integration**: NapCat + OneBot 11 protocol support
- **WeChat Integration**: WeChatPad adapter (experimental)
- **OpenClaw Bridge**: Gateway API integration for OpenClaw
- **Voice Support**: SILK/AMR transcription, edge-tts synthesis

### Quality Assurance
- **100+ Unit Tests**: Comprehensive test coverage
- **Knowledge Base Audit**: Automatic quality checks
- **Integration Tests**: End-to-end workflow verification

## 📦 Installation

```bash
# Basic install
pip install partner

# With optional features
pip install partner[all]
```

## 💬 Usage

```bash
# Configure (auto-detects agents, configures gateway, sets up cron)
partner setup

# Check status
partner status

# Talk to Partner (through your agent)
"Hey Partner, what have you been doing?"
```
