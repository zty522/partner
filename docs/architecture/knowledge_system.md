# 分级文档与动态上下文系统

## 目标

保留完整知识，但每一步只加载当前决策需要的内容。文档是长期记忆，不是每次全量注入的 prompt。

## 分级

- L0：`docs/catalog.yaml` 路由元数据，每次可读。
- L1：自我定位、真实性规则、当前基线，小而稳定。
- L2：领域、架构、项目和 playbook，按实例/任务选择。
- L3：当前项目状态、最新 Receipt、任务证据，在运行时生成。
- L4：原始日志和历史归档，只在追溯时读取相关片段。

## 选择流程

1. 规则层强制选择 L1，并按实例和标签筛选 L2。
2. 语义选择只在候选集中排序，不得越过 authority/default_load 约束。
3. 加载最新项目状态和 Receipt 作为 L3。
4. 按字符预算截断，记录选了什么、为什么、用了多少预算。

## 不变量

- L4 不默认加载。
- 过时文档不能覆盖 canonical/current 事实。
- 每个片段带来源，不生成无法追溯的拼接上下文。
- 选择结果不直接修改原文档。
- 缺少必读文档时显式失败，不静默降级为猜测。
