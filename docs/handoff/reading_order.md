# LLM / Agent 接手阅读顺序

## 必读

1. 根目录 `AGENTS.md`。
2. `docs/README.md`。
3. `docs/current_status.md`。
4. `docs/catalog.yaml`，根据当前实例和任务选择 L2/L3 内容。

## 历史文档规则

Sprint、`change_log.md` 和 `evolution_journal.md` 仅用于追溯。不得从历史记录推断当前实例活性或当前能力。
需要历史经验时，先通过目录/标签缩小范围，再读取对应片段，不整库注入。
